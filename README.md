A one-line roast of the smart speaker that lives on my shelf — deaf to its owner, attentive to the television.

> "My smart speaker ignores me when I shout its name, then answers a question from the TV — it's a butler who only works for the furniture."

## How it works

`main.py` holds the entry line as a constant, checks it against the kit's gate (UTF-8 text, 1–200 characters, not only whitespace, a single line with no control characters or leading/trailing whitespace), and writes it to `/output/entry.txt` when run with `python3 main.py`.
